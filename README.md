## 📌 Overview

An end-to-end Machine Learning desktop application with a graphical user interface built using CustomTkinter. Supports regression, classification, and clustering tasks with automated evaluation.

## 🎯 Key Features

- ✅ **GUI Interface** — User-friendly CustomTkinter desktop app
- ✅ **Data Preprocessing** — Scaling, encoding, missing value handling
- ✅ **Regression** — Linear Regression, Ridge Regression
- ✅ **Classification** — Logistic Regression, Random Forest
- ✅ **Clustering** — K-Means with silhouette score
- ✅ **Auto Evaluation** — RMSE, Accuracy, Silhouette Score
- ✅ **Visualization** — Matplotlib & Seaborn charts

## 🛠️ Technologies

| Category | Tools |
|----------|-------|
| GUI | CustomTkinter |
| ML | Scikit-learn |
| Data | Pandas, NumPy |
| Viz | Matplotlib, Seaborn |
